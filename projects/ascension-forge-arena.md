# Ascension Forge Arena

**Singapore Polytechnic | Full-stack web development coursework**

Ascension Forge Arena is a gamified wellness website developed as coursework. It brings together frontend interaction, server-side application logic, user management and a relational database.

## Project scope

- **Frontend:** HTML, CSS and JavaScript for the user-facing interface and interactive experience.
- **Backend:** Node.js and Express.js for request handling and application routes.
- **Data:** MySQL for relational data storage, with create, read, update and delete (CRUD) operations.
- **Application structure:** An MVC-style separation of models, controllers and routes, supported by middleware, services and configuration modules.
- **Authentication:** JWT-based authentication within the coursework implementation.
- **API design:** REST-style endpoints to connect the frontend to the backend.

## What this demonstrates

The project broadened my experience beyond model development and data analysis. It involved organising a full-stack codebase, connecting client and server components, implementing data-backed interactions, and thinking about how authentication fits into a web application.

This was an academic application, not a claimed production service.
